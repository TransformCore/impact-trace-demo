# Contributing

Thanks for helping improve ImpactTrace Demo.

## Before opening a pull request

- Keep the change focused and explain the user-visible or developer-visible effect.
- Run `npm run build`.
- Run `npm run test:e2e`.
- Update the README when setup, commands, or project behavior changes.
- Do not commit generated assets, reports, test results, or local build output.

Please use clear commit and pull request descriptions. By contributing, you agree that your
contribution is provided under the project's MIT License.
